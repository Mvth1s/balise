# Maquette de référence

Fichiers exportés d'un outil de maquettage. Ce sont des pages HTML enrichies (balises x-dc, sc-for, sc-if) : lis-les comme du HTML de référence pour la mise en page, les textes, les couleurs et la structure accessible. Ne les réutilise pas tels quels dans le code.

- Main.dc.html : accueil
- Analyse.dc.html : analyse en cours
- Rapport.dc.html : rapport desktop
- Rapport-mobile.dc.html : rapport sur mobile
- Cookies.dc.html : bandeau de consentement GA4
- Gestion-cookies.dc.html : page de gestion des cookies

Les données affichées (scores, nombres d'éléments, numéros de critères) sont fictives ou à vérifier.
